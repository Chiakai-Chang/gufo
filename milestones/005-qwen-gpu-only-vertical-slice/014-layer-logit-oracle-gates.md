## Required Context

- Matching text or top-1 tokens is insufficient. The current Python teacher suite has 78 scored positions with a fixed hash, and native kernels require independent layer and full-logit evidence.

## Goal

Wire strix-capture and strix-compare-compatible native artifacts for selected embedding, norm, QKV/RoPE, attention, DeltaNet state, MLP, residual, final hidden, and full-logit boundaries against pinned reference artifacts.

## Non-Goals

- Regenerating goldens in CI
- Changing quality thresholds to admit failures
- Full 27B oracle capture
- Capability grading

## Definition of Done

- [ ] `strix-capture` and `strix-compare` are built and installed by the Nix package before their first use in this card.
- [ ] Artifacts record source/model/tokenizer/suite/runtime/storage/accumulation identities and checksums.
- [ ] Comparison identifies the first divergent token, layer, component, and element with exact or declared atol/rtol semantics.
- [ ] The 78-position matched-token suite rejects vocabulary/hash mismatches and reports complete normalized distribution metrics.
- [ ] Goldens are immutable inputs and never regenerated by tests.

## Development Loop

```sh
nix develop -c cmake --preset hip-test
nix develop -c cmake --build --preset hip-test
git add -A
nix build
nix develop -c ./result/bin/strix-compare --self-test --json
nix develop -c ctest --preset hip-test --output-on-failure -R 'qwen35_(layer_boundary|logit_artifact)'
```

## Hardware Validation

```sh
mkdir -p artifacts/m005
nix develop -c ./result/bin/strix-capture --model artifacts/quant --route GPU_ONLY --suite tools/suites/teacher.json --out artifacts/m005/native-logits && nix develop -c ./result/bin/strix-compare --reference artifacts/teacher --candidate artifacts/m005/native-logits --thresholds tests/models/qwen35/thresholds.json --json
```

## Output Artifacts

- Checksummed native layer-boundary artifact
- 78-position native-vs-teacher full-logit metrics JSON
- Immutable threshold declaration

## Stop Conditions

- Stop on suite, vocabulary, tokenizer, or source revision mismatch.
- Stop at first unexplained layer divergence; never average away a numerical mismatch.
